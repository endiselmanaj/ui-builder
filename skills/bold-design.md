# Bold Design

Aim for a vibrant, high-energy, attention-grabbing aesthetic.

- Saturated colors and gradients (pinks, purples, electric blues, neon)
- Big type: oversized headings, strong weight contrast
- Generous shadows, glows, rounded corners
- Playful spacing — overlapping elements, off-grid layouts welcome
- Prominent calls-to-action with high-contrast buttons
- Use gradients on backgrounds, buttons, accent text
